## Findings addressed in this follow-up

1. **Missing receipts and impossible scores could reach reporting.** The guarded
   entry point now requires independent evidence admission. Negative controls
   cover absent hooks/settings/classification, wrong live model, mismatched
   provenance/usage/hash, duplicates, nonfinite/out-of-range scores, inconsistent
   success flags, omitted original fields and malformed identities. Unreadable
   input also replaces a stale prior verdict. All 170 original rows still pass
   admission and yield the unchanged failed cost gate.
2. **Setup, failures and unknown exposure were not treated consistently.** The
   lifecycle library retains every attempt, counts known setup/failure costs,
   marks unknown usage explicitly, journals dispatch first, rejects higher caps
   on resume and prevents further dispatch after a failure or interruption.
   This is tested groundwork; it is not yet an integrated paid supervisor.
3. **Final workspaces were lost and graders were visible to the agent.** Retained
   archives have per-file/archive hashes and corruption detection. The actual
   17 frozen task fixtures now prepare and regrade identically twice with a clean
   synthetic agent unable to see truth. A known-positive/negative grader control
   also discriminates 1 from 0. The production client image still needs this
   boundary; the old THOL image contains grader material and is used only for
   preparation/grading, never as the isolated agent in this rehearsal.
4. **Installer exit status overstates activation.** Caveman returned exit zero
   after a skills-install failure. Codex parsed empty homes successfully even
   when no integration had been installed. The other token-optimizer installer
   detected no Codex until its documented AGENTS.md marker existed. Admission
   now reports configuration, real-client receipts and known behavior separately.
5. **Synthetic hooks were insufficient evidence of native client wiring.** The
   real Codex CLI now talks to a loopback protocol fixture with no credentials
   and Docker networking disabled. It must execute the known file read and
   finish a turn on the same requested model/effort. Audited vendor commands
   prove actual native-hook execution. Project integrations require explicit
   trust inside the disposable fixture; Graphify otherwise looked installed
   while Codex disabled its configuration. Synthetic protocol usage is labelled
   and excluded from every cost result.
6. **Compatibility and version labels need independent checks.** Edgee's musl
   release fixes the old glibc startup failure, but gateway/account routing is
   still pending. Official tokf/TRS binaries fail on this image's glibc; unmodified
   official source was compiled in network-denied layers and is recorded as a
   separate source-built variant. Pyra's v1.1.0 binary says `dev`; npm
   token-optimizer 0.2.2 says v0.2.1 in help. These discrepancies remain visible.
   tokf's CLI release is `tokf-v0.2.54`, not its catalog-types release.
7. **Same-name packages are not identity evidence.** PyPI's `copium` belongs to
   Bobronium, whereas this field specifies iKislay/copium. It was not substituted.
   withmewtwo/token-slayer remains unresolved; an unrelated same-name repository
   was not used. Missing registry distributions are recorded rather than replaced.
8. **A marker anywhere in a payload is a weak correctness check.** Headroom's
   compression fixture now requires the full failure line in the matching tool
   result. A negative control retains the same marker only in the user prompt
   and must fail. Routing/model/effort changes and no reduction must also fail.
   Wrapper persistence is reported, and disposable Docker teardown bounds it.
